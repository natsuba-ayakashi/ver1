# TRPG Log Analyzer

TRPG ここふぉりあのセッションログを解析し、キャラクターごとの判定数や技能別の成功率、クリティカル／ファンブル率をまとめて表示するツールです。  
非公式だし趣味だし全部AIで作ってます。

## 使い方
1. [Releases](https://github.com/natsuba-ayakashi/ver1/releases/tag/ダイス解析ツール) ページから最新版の `main.exe` をダウンロードしてください。
2. ダウンロードした exe ファイルをダブルクリックで実行します。
3. 解析したいログファイルを選択すると、自動で集計結果が表示されます。

## 出力される内容
- **キャラクターごとの判定数・クリティカル／ファンブル率**
- **技能別の成功／失敗数一覧**
- **不明技能の詳細（クリファン以外も含めて常時出力）**

## 動作環境
- Windows 10 / 11
- Python は不要（exe 版は単体で動作します）
